-れた/れる = passive
	got affected by an action in a passive sentence  )

としても = even if

ので = because, since

-てくれる = doing specially for me

-たら = hypothetical, "if"

-てくる = something comes towards the speaker

-んだ = explanatory
	you see

-てしまう/ちゃう = unfortunately ended up doing
	しまう = to finish
	て + しまう = end up doing

-として = As / in the role of
	-としては → としちゃ

-さ = Sentence-ending particle, "you know", "okay"

-ておく = do something upfront, in advance.

-ている → てる → てん

-のだったら/んだったら  = if it’s the case that

-そう = it seems
	what comes before behaves like a な adjective.
		なってしまう → なってしま==い==そう
		なっちゃう → なっちゃいそう = seems like it will end up becoming

-てもらう = to have someone do it

-ないと → ないといけない = must/have to

-ておく = make it ahead of time (or now) and leave it in place when needed
	also can mean *like that*
	for now / for the time being

-ければ/えば = conditional form
	なければ = if there's no ... / if not
		えば =  う verbs
		ければ = い adjectives
